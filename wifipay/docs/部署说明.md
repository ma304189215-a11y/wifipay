# WIFIPAY 部署说明

付费 WiFi 认证计费插件，三个版本一个包，靠页面上的「部署形态」切换。

---

## 一、三种方案怎么选

| | 谁跑插件 | 谁做路由 | 无线谁发 | 认证在哪 | 适用场景 |
|---|---|---|---|---|---|
| **A 单机全包** | 一台好机器 | 同一台 | 自带或外接 AP | 本机 | 软路由、N100、J4125、商用小主机 |
| **B 弱机 + AP** | N1 这类弱机 | N1 | **外接 K2P 等做 AP** | 本机 | 手里只有 N1 这种单核机器 |
| **C 前后端分离** | N1 只拦截 | N1 或主路由 | 外接 | **后端机器** | 几十上百人同时认证的场子 |

### A：单机全包

一台性能足够的机器装了就完事，套餐、兑换码、广告、订单全在本机。

```
设备 → 这台机器（路由 + NK 拦截 + 认证页）→ 外网
```

页面选 `单机全包`，别的不用配。

### B：弱机 + AP

本机（N1）做网关和认证，无线交给 K2P。

```
设备连 WiFi
   ↓
K2P（关掉 DHCP、关掉路由，LAN 口接 N1 的 LAN）
   ↓ 网线
N1（跑 wifipay：拨号/ DHCP / DNS / 认证 / 限速）
   ↓
光猫或上级网络
```

**前提：N1 要有第二个网口**（原机只有一个 eth0，需要 USB 网卡），或者用 VLAN 单臂路由。

配置步骤：

1. N1 上把 `network.lan.proto` 设成 `static`，配好网段
2. N1 上开 WAN（USB 网卡或 PPPoE）
3. N1 上开 DHCP（`dhcp.lan.ignore=0`）
4. **K2P 上关 DHCP**，LAN 口接 N1 的 LAN 口
5. wifipay 页面选 `弱机 + AP`

插件功能不变，只是网络拓扑变了。

### C：前后端分离

本机只做 nft 拦截 + 把 HTTP 转给后端，认证页、兑换码、订单全在后端机器。

```
设备 → N1（nft 拦截 + dnat）→ 后端机器（portal + 认证 + 计费）
                                      ↓
                                  N1 定时同步白名单
```

**后端部署见第五节。**

## 二、三种形态怎么切

LuCI → 服务 → 付费 WiFi → 部署形态

```
单机全包     deploy_mode = full
弱机 + AP    deploy_mode = ap
前后端分离   deploy_mode = split
```

切换后必须点一次「重新加载规则」（或者 `wifipay stop && wifipay start`）。

也可以用命令行：

```sh
uci set wifipay.settings.deploy_mode='split'
uci set wifipay.settings.backend_url='http://<后端IP>:9000'
uci set wifipay.settings.backend_key='你的密钥'
uci commit wifipay
wifipay stop && wifipay start
```

### 本机代码里跟 split 相关的只有三处

```
net.sh 第 27 行      deploy_mode=split 时把 redirect 换成 dnat
loop.sh sync_backend  每 sync_interval 秒从后端拉白名单
deploy.js 页面        切模式和填后端地址
```

其他文件在三种模式下完全一样。

## 四、后端服务（方案 C 用）

### 拉代码

云盘里的 `wifipay-backend-src.zip`，解开放到任意一台 Linux：

```sh
unzip wifipay-backend-src.zip -d /opt/
cd /opt/backend
```

### 目录结构

```
backend/
├── srv.py        后端服务（Python 3，只用标准库）
├── www/          认证页（从插件里拷的）
└── data/         运行时生成：db.json（套餐/兑换码/设备/订单）
```

### 直接跑（最简单）

```sh
cd /opt/backend
WP_KEY=你的密钥 WP_PORT=9000 nohup python3 srv.py > srv.log 2>&1 &
```

### systemd 托管

```ini
# /etc/systemd/system/wifipay-backend.service
[Unit]
Description=WIFIPAY Backend
After=network.target

[Service]
WorkingDirectory=/opt/backend
Environment=WP_KEY=你的密钥
Environment=WP_PORT=9000
ExecStart=/usr/bin/python3 /opt/backend/srv.py
Restart=always

[Install]
WantedBy=multi-user.target
```

```sh
systemctl enable --now wifipay-backend
```

### Docker

```dockerfile
FROM python:3-alpine
WORKDIR /app
COPY srv.py .
COPY www/ ./www/
ENV WP_KEY=changeme WP_PORT=9000
EXPOSE 9000
CMD ["python3", "srv.py"]
```

```sh
docker build -t wifipay-backend .
docker run -d --name wifipay-backend -p 9000:9000 \
  -e WP_KEY=你的密钥 -v /opt/wifipay-data:/app/data wifipay-backend
```

### 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/` | 认证页 |
| GET | `/api/plans` | 套餐列表 |
| GET | `/api/status?mac=` | 查剩余时长 |
| GET | `/api/trial?mac=` | 开试用 |
| GET | `/api/redeem?mac=&code=` | 兑换 |
| GET | `/api/sync` | 白名单同步（要 X-WP-Key） |
| POST | `/api/admin/codes` | 生成兑换码（要 X-WP-Key） |

`/cgi-bin/wifipay?act=xxx` 也兼容，页面不用改。

### 生成兑换码

```sh
curl -X POST -H "X-WP-Key: 你的密钥" -H "Content-Type: application/json" \
  -d '{"plan":"p60","count":100}' http://后端IP:9000/api/admin/codes
```

## 五、测试清单

装好后按顺序过一遍：

```sh
# 1. 体检
wifipay doctor

# 2. 自检（应该 33 项全过）
wifipay selftest

# 3. 看规则
nft list table inet wifipay | grep 'dport 80'
#  full/ap 模式：redirect to :8088
#  split 模式：dnat to 后端IP:9000

# 4. 认证页
curl -I http://本机IP:8088/
```

客户端侧（用一台**不在白名单**的设备）：

```
1. 连 WiFi，网关指向本机
2. 打开 http://任意网站 → 应该跳认证页
3. 点试用 → 能上网
4. 断开重连 → 试用次数用完，不能再试
5. 兑换码 → 放行
6. 测速 → 接近 rate_down 设定值
```

split 模式额外验证：

```sh
# 本机白名单同步
cat /etc/wifipay/allowed
# 应该能看到后端里的设备

# 后端不可达时的兜底（保留上次白名单，不会全断）
```

## 六、常见问题

**切换 deploy_mode 后没反应**
→ 必须 `wifipay stop && wifipay start`

**split 模式设备打开页面是 404**
→ 后端没起来，或者 backend_url 写错（要带端口）

**同步一直是空的**
→ backend_key 和后端 WP_KEY 不一致

**主路由模式下 portal 挂了**
→ 看门狗 3 分钟自动放行 30 分钟，看 `logread | grep wifipay`

**自己也被拦了**
→ `wifipay trust-online` 或者 `wifipay panic 10`

## 七、卸载

```sh
wifipay stop
apk del luci-app-wifipay
rm -rf /etc/wifipay /etc/config/wifipay /www/wifipay
```

后端：

```sh
systemctl disable --now wifipay-backend
rm -rf /opt/backend
```
